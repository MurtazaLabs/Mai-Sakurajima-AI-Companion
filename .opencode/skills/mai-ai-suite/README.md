# Mai AI Suite

Version: 2.0.0

Author: Syed Murtaza

---

## Overview

Mai AI Suite is the central engineering intelligence layer for the Mai Sakurajima AI Assistant.

It automatically classifies development tasks, selects the appropriate engineering specialist, coordinates multi-domain workflows, and generates implementation guidance.

Rather than acting as a single coding assistant, Mai AI Suite functions as an AI Engineering Team composed of multiple specialist roles working together under one orchestrator.

---

## Purpose

This skill is designed to:

- Understand the Mai AI codebase
- Review large Python projects
- Perform architecture analysis
- Review software quality
- Audit AI systems
- Design memory systems
- Improve prompts
- Plan new features
- Generate documentation
- Coordinate engineering workflows
